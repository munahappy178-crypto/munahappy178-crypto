## 🚀 Featured Project

### 🎟️ Hargeisa Events Pro

**A Cloud-Based Event Management Platform for Hargeisa, Somaliland**

Hargeisa Events Pro is a digital platform designed to modernize the
local event-management ecosystem by bringing customers, venues, and
vendors together through a centralized online experience.

The project focuses on simplifying event discovery, booking,
coordination, and vendor management while reducing reliance on
traditional manual processes.

**Core Focus:**

- Vendor Management
- Digital Booking
- Centralized Information
- User-Friendly Experiences
- Cloud-Based Architecture
